# Твич, Хаос и Котики 2

2D-игра для Twitch: зрители входят в лобби, делятся на команды и покупают бустеры в свой ход.

Есть два режима:

- **Онлайн** — браузерный клиент и авторитетный сервер на Godot. Один сервер держит несколько каналов, на каждый канал — одна сессия: лобби, игра или конец игры.
- **Локальный** — обычный запуск проекта в Godot без сервера, с подключением к чату со своего компьютера.

## Управление в чате

- `!join` — участвовать в лобби.
- `!1`–`!8` — купить карточку магазина в свой ход.
- `!0` — пропустить ход.
- `!reset` — команда стримера: вернуться в лобби, сохранив игроков и настройки.

## Онлайн-режим

### Из чего состоит

- `scenes/server.tscn` — headless-сервер Godot. Считает матч, таймер, магазин, очки и конец игры.
- `scripts/server/server_main.gd` — WebSocket-сервер и сессии каналов.
- `scripts/server/channel_session.gd` — одна сессия на нормализованный канал Twitch.
- `scripts/net/network_client.gd`, `scripts/net/scene_router.gd` — браузерный клиент и переключение сцен по фазе сервера.
- `tools/serve_web.js` — раздача Web-сборки и прокси `/ws` на игровой сервер (локально и в Docker).
- `Dockerfile`, `docker/start.sh`, `render.yaml` — сборка и запуск одним Docker-сервисом на Render.

Чат читает сервер: браузер не подключается к Twitch напрямую. Один канал — одна активная игра. Повторный вход в тот же канал возвращает в текущее лобби, игру (как зритель) или конец игры.

### Запуск сервера

```powershell
& "C:\Users\Никита\Godot_v4.7.1-stable_win64.exe\Godot_v4.7.1-stable_win64_console.exe" `
  --headless --path "C:\Users\Никита\Twitch Chaos Cats 2" `
  res://scenes/server.tscn -- --port=8080
```

Для проверки без настоящего Twitch-чата добавьте `--debug`: тогда доступны команды `debug_join` и `debug_say` по WebSocket.

### Сборка Web-клиента

```powershell
New-Item -ItemType Directory -Force -Path build\web | Out-Null
& "C:\Users\Никита\Godot_v4.7.1-stable_win64.exe\Godot_v4.7.1-stable_win64_console.exe" `
  --headless --path "C:\Users\Никита\Twitch Chaos Cats 2" `
  --export-release "Web" "build/web/index.html"
```

Нужны установленные шаблоны экспорта Godot 4.7.1 (достаточно Web-шаблонов).

### Запуск Web-клиента локально

```powershell
node tools/serve_web.js
```

Открыть `http://127.0.0.1:8090`. Страница и WebSocket работают с одного адреса: запросы на `/ws` проксируются на `127.0.0.1:8080`.

Если страница размещена отдельно от сервера, адрес можно задать параметром:

```text
http://127.0.0.1:8090/?server=ws://127.0.0.1:8080
```

Для HTTPS-туннеля клиент по умолчанию использует `wss://<тот же хост>/ws`, поэтому удобнее проксировать `/ws` через тот же домен.

### Деплой на Render

Игра разворачивается одним Docker Web Service: Node отдаёт Web-клиент и проксирует `/ws` на Godot-сервер внутри того же контейнера.

1. Запушьте репозиторий в GitHub (ветка `main`).
2. В Render Dashboard: **New → Blueprint**, подключите репозиторий и примените `render.yaml`.
   Либо **New → Web Service → Docker**, план **Free**, регион **Frankfurt**, health check `/healthz`.
3. Render сам соберёт `Dockerfile` (первая сборка скачивает шаблоны экспорта Godot, это долго) и запустит контейнер.
4. Откройте выданный `https://<имя>.onrender.com` и войдите в канал.

Настройки:

- `SESSION_IDLE_TIMEOUT` — через сколько секунд закрывать сессию канала без клиентов (по умолчанию `600`, `0` — выключить).
- `PORT` — внешний порт, Render задаёт сам.
- `GODOT_PORT` — внутренний порт Godot-сервера (по умолчанию `8080`).
- `WS_PORT`, `WS_HOST`, `WEB_ROOT` — обычно задавать не нужно: `start.sh` и `serve_web.js` используют значения по умолчанию.

Особенности Free-тарифа: 512 МБ памяти, 0.1 CPU, сервис засыпает после 15 минут без входящего трафика, холодный старт около минуты. Сессии хранятся в памяти: рестарт или деплой их очищает. Клиент сам переподключается, а сессии без клиентов удаляются через 10 минут. Ответы в Twitch-чат не отправляются: для них нужен OAuth с `chat:edit`.

### Проверка без Twitch

Запустите сервер с `--debug`, откройте Web-клиент и войдите в канал. Затем добавьте тестовых игроков:

```powershell
node tools/debug_join.js <канал> 3
```

Вместо реального сообщения в чат можно отправить команду от имени игрока:

```powershell
node tools/debug_say.js <канал> <логин> "!0"
```

### Переменные окружения `tools/serve_web.js`

- `PORT` — порт страницы, по умолчанию `8090` (в Render задаётся автоматически).
- `WS_PORT` — порт игрового сервера, по умолчанию `8080`.
- `WS_HOST` — хост игрового сервера, по умолчанию `127.0.0.1`.
- `WEB_ROOT` — папка со статикой, по умолчанию `build/web`.

## Локальный режим

1. Открыть `project.godot` в Godot 4.7.1.
2. Нажать F5.
3. Ввести канал Twitch и максимальное число игроков.
4. После входа в чат зрители пишут `!join`.

Прямой запуск `scenes/game.tscn` включает демо-режим с автопилотом.
